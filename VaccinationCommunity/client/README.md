# Giao diện Cổng theo dõi tiêm chủng cộng đồng

Chạy cài đặt từ thư mục cha `VaccinationCommunity`, nơi có workspace package.json và package-lock.json chung.

Xem [hướng dẫn đầy đủ](../README.md). Từ thư mục cha, dùng `npm run dev` để chạy cả API và giao diện; dùng `npm run dev --workspace client` khi chỉ cần Vite.
