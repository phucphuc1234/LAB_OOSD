# Giao diện hiện tại

Bản giao diện mới sử dụng React, Bootstrap và Lucide với theme y tế nền sáng. Các màn hình, điều hướng điện thoại, đăng nhập/đăng ký và dashboard đã được cập nhật; phần trang trí WebGL/Three.js và phụ thuộc liên quan đã được bỏ.

Hai màn hình theo dõi sau tiêm sử dụng API và stored procedures thật. Không có chế độ mock dữ liệu tự động trong ứng dụng; fixture chỉ xuất hiện trong tests/e2e.

Cài và chạy từ thư mục cha theo [README dự án](../README.md). Database và backend cũng có thay đổi; cần cài SQL trước khi đăng nhập.
